- 05 Aakriti → цифры стеклянными плашками на фото; три преимущества с тонкими иконками → блок «Гарант».
- 06 этапы стеклом на фоне гор → блок «Как купить дом» (шаги эскроу) на фото гор или посёлка.
- 07 Agressov → проекты высокими полосами с номерами 01–03 → три посёлка.
