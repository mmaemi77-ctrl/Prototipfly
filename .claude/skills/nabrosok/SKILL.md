# Набросок под ключ

Анастасия присылает скриншоты (профиль, посты, переписка с ответом клиента) и одну фразу вроде «Набросок для UNiTy». Дальше всё делается без остановок, кроме одного вопроса про имя репозитория. Правила из CLAUDE.md главнее навыков formi-prototip и razbor-klienta там, где они расходятся.

## 0. Сразу, первым действием
1. Найти клиента в трекере «Мои клиенты» (https://claude.ai/artifact/CzgWNWUNhT8ciAFcdFMztu, коллекция `clients`, ArtifactData `list` с `out_dir`, потом grep по имени). Взять факты, контакт, первое сообщение, цену.
2. Спросить имя публичного репозитория через AskUserQuestion: 2–3 варианта, первый с пометкой (Recommended), формат `<бренд>-<место>` латиницей (пример: unity-elbrus). В вопросе попросить создать пустой Public-репозиторий без README на github.com/new. Пока она создаёт, работать дальше.

## 1. Факты
- Только со скриншотов и из открытых источников, к каждому факту источник.
- Живые детали: дословные подписи постов, цифры лайков и репостов, хайлайтс.
- Фото и логотип вырезать из скриншотов в `<папка>/img/` (Pillow; координаты экрана × 1179/923 для скриншотов iPhone). Проверить, что на кадр не попали значки «1/2», отметки людей, интерфейс.
- Чего нет (цены, вместимость, ИП, условия) → в вопросы клиенту, на сайте «уточним».

## 2. Конкуренты
- 5–6 из того же места, WebSearch (несколько поисков в одном ходе). Агрегаторы (101hotels, mirturbaz, otello, Яндекс Путешествия) из облачной сессии не открываются: брать данные из поисковой выдачи и писать в разборе «по открытым карточкам и поисковой выдаче на <дата>».
- По каждому: адрес, формат, цена «от», фишки, рейтинг, ссылка. Тон уважительный.

## 3. Файлы в папке клиента `<папка>/`
Образец: `unity-elbrus/` (дома посуточно), `sputnikpdr/` (услуги с записью). Копировать устройство, менять содержание и цвета под бренд.
- `analiz.html` — разбор: шапка, главное в пяти пунктах, что уже сильное (с галереей их фото), что мешает, что спрашивают клиенты и сезон, конкуренты + «что стало нормой» / «чего не встретила», задачи сайта, было и стало (переписка), идеи, вопросы, подвал FOR.MI. Блока «Что уже есть в наброске» и ссылки на главный экран нет.
- `index.html` — главный экран с рабочей формой (выбор, календарь или фото, согласие на обработку данных, окно «Так заявка придёт вам»), ниже структура блоками, «Что дальше», подвал с политикой и согласием. Плашка «это набросок, никуда не отправится».
- `struktura.html` — слайды структуры, каждый `<div class="slide">` 540×675 (2–3 слайда, последний «Что видите вы», если есть польза для владельца). Не называть классы одной буквой.
- `maket.json` — заголовок о главной выгоде и 2–3 плашки (пример: `unity-elbrus/maket.json`).

## 4. Картинки и проверка
```
node _instrumenty/maket.js <папка>      # glavnyi-maket.png 1080×1350, ноутбук + телефон
node _instrumenty/kartinki.js <папка>   # struktura-N.png 1080×1350, og-превью, проверка ошибок и прокрутки
```
Удалить промежуточные glavnyi-noutbuk.png и glavnyi-telefon.png. Посмотреть каждую картинку глазами (Read), исправить, перезапустить.
Проверка текста: нет «шаблон», «ИИ», «нейросеть», выдуманных цифр; правила текста Анастасии (без длинных тире больше одного-двух на абзац, без канцелярита).

## 5. Публикация
1. Коммит в Prototipfly на рабочую ветку, push.
2. `add_repo` (owner mmaemi77-ctrl, repo <имя>, access push). Если репозитория ещё нет, сказать Анастасии создать и написать «готово».
3. Склонировать в scratchpad, скопировать содержимое папки клиента в корень, добавить пустой `.nojekyll`, коммит и push в main.
4. Напомнить: Settings → Pages → Deploy from branch → main / root. Ссылка на разбор: `https://mmaemi77-ctrl.github.io/<имя>/analiz.html`.

## 6. Трекер
Прочитать документ клиента (`get`), затем `update` с `if_version`: в `links` добавить «Разбор» и «Главный экран и структура», `nextStep` (включить Pages и отправить), `notes` (что сделано, что заглушка, имя репозитория), `replies` (ответ клиента с датой). Статус не менять, пока она не скажет, что отправила.

## 7. Что отдать Анастасии
- Картинки через SendUserFile: struktura-1…N.png и glavnyi-maket.png (именно в таком порядке для отправки клиенту).
- Одно сообщение клиенту по правилам CLAUDE.md: что сделала, блоки структуры одной фразой, «сделала для вас разбор конкурентов» и одна ссылка на разбор, оговорка про заглушки, вопрос «Как вам структура? Что бы поставили первым?». Без цены, без созвона.
- Коротко: что узнала, что заглушка, вопросы клиенту, что обновлено в трекере.
